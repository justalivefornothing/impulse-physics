# Impulse Physics

From-scratch 2D rigid-body physics engine with SAT collision, sequential-impulse solving, and joints — wrapped in an interactive sandbox.

## Features

- Rigid bodies with position / velocity / angular velocity
- Separating Axis Theorem (SAT) collision detection
- Sequential impulse solver for contacts and joints
- Spawn, fling, and stack shapes with live debug overlays

No third-party physics library.

## Run

```bash
npm install
npm run dev
npm test
npm run build
```
